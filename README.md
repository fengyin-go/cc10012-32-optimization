# 多维数据探查分析工具

离线版多维数据探查分析工具，涵盖数据源接入、交互查询、聚合统计、图表看板、预警通知与数据导出，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

引擎测试（分批写入、断点续做、完整性校验、并发与发布门禁）：

```bash
cd frontend
npm test
```

## 导出数据明细文件机制

数据导出不再在内存里一次性拼接整份 CSV，而是由 `frontend/src/api/export-detail.ts`
引擎按批写入可断点续做的「导出数据明细文件」，`local-service.ts` 是页面调用链的唯一更新点：

- **分批写入 + 安全断点**：每批写一个独立分片，整批落盘并通过分片自检后才推进
  `nextRow` 断点；中断时停在最近安全断点，失败重试只补未完成行，跨行文本不会留下半行。
- **下载区不可见半成品**：分片只在暂存区累积；只有通过「数据行数 + 完整摘要 + 滚动摘要」
  校验的文件才会发布，下载入口（`getPublishedFile`）每次读取都重新校验，截断或篡改一律拒绝。
- **断点续做 / 修订两条版本轨迹**：中断后可沿用原文件续写（v1），或封存失败分片后
  发布修订文件（v2）；封存件不进入下载区，冲突处理保留来源（origin / revisedFromVersion）。
- **并发只认可一份文件**：写入者锁（owner + TTL）拒绝并发写入者，重复执行幂等返回同一份文件。
- **可检查、可重开**：断点位置、文件行数、完整性摘要、版本轨迹与失败原因都在
  「数据导出」页面可核对；页面重开时过期锁自动恢复为可续做的中断态，状态持久化在本地存储。
- **报告附件一致**：报告生成与导出入口共用同一份明细文件取数口，通过校验后只保存
  附件摘要（行数、摘要、版本），报告附件不会拿到截断数据。
- 「数据导出」页内置 12000 行大结果集演示：在 8000 行注入写入中断，可验证完成前
  下载区无文件、续做后完成文件正好 12000 行。

## 业务模块

| 模块 | 目录 | 业务对象 | 主要字段 |
| --- | --- | --- | --- |
| 交互查询 | `query` | 查询语句 | 语句编号、查询表达式、目标数据集 |
| 可视化图表 | `chart` | 图表配置 | 图表编号、图表名称、图表类型 |
| 数据源接入 | `source` | 接入配置 | 配置编号、连接类型、接入地址 |
| 聚合计算 | `aggregate` | 聚合方案 | 方案编号、聚合函数、目标字段 |
| 数据筛选 | `filter` | 筛选规则 | 规则编号、目标数据集、筛选字段 |
| 报告生成 | `reportgen` | 报告模板 | 模板编号、模板名称、包含图表 |
| 异常检测 | `anomaly` | 检测规则 | 规则编号、监控指标、基线均值 |
| 多维下钻 | `drill` | 下钻路径 | 路径编号、起点维度、下钻层数 |
| 对比分析 | `compare` | 对比方案 | 方案编号、基准数据集、对照数据集 |
| 分析流水线 | `pipeline` | 流水线节点 | 节点编号、节点类型、输入源 |
| 数据集管理 | `datastore` | 数据集定义 | 数据集编号、数据集名称、来源表名 |
| 趋势预测 | `forecast` | 预测模型 | 模型编号、模型类型、训练数据集 |
| 预警通知 | `alert` | 预警规则 | 规则编号、关联指标、阈值上界 |
| 查询缓存 | `cache` | 缓存策略 | 策略编号、目标查询、缓存键规则 |
| 数据标签 | `tag` | 标签定义 | 标签编号、标签名称、计算表达式 |
| 数据导出 | `export` | 导出任务 | 任务编号、查询SQL、导出格式 |
| 数据分享 | `share` | 分享链接 | 链接编号、目标数据集、访问密码 |
| 定时任务 | `schedule` | 调度配置 | 配置编号、关联任务、调度表达式 |

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-studio:entries` 这一项，或调用 `resetModule(模块)`。
